# Fixtures

This directory contains checked-in sample packages for schema and package-level
validation.

## `v3-mid/`

Golden fixture for `cs2-demo-format` v3.

- **Map:** `de_anubis`
- **Formal rounds:** 21
- **Export profile:** research (`--research`)
- **Schema version:** `cs2-demo-format/3.0`
- **Generated by:** `cs2df` reference exporter
- **Contents:** all required files plus `shots.json`, `replay.json`, and `duels.json`

Validate it with:

```bash
pnpm validate:fixtures
```

Regenerate from the local benchmark demo, assuming `cs2-demo-analysis-kit` is
checked out as a sibling repository:

```bash
cd python
uv run cs2df export \
  ../../cs2-demo-analysis-kit/fixtures/_bench/mid.dem \
  -o ../fixtures/v3-mid.zip \
  --research

rm -rf ../fixtures/v3-mid
mkdir -p ../fixtures/v3-mid
unzip -q ../fixtures/v3-mid.zip -d ../fixtures/v3-mid
rm ../fixtures/v3-mid.zip
cd ..
pnpm validate:fixtures
```

The large files in this fixture are intentional: `replay.json` and `duels.json`
show the real columnar stream shape and size.
